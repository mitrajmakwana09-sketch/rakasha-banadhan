============================================================
              RAKSHA BANDHAN SURPRISE WEBSITE
============================================================

Project Name:
Raksha Bandhan Surprise

Description:
This is a beautiful interactive Raksha Bandhan surprise
website made using HTML, CSS and JavaScript.

The website is designed to create a special surprise
experience with animations, messages, gift opening,
floating hearts, particles and a final Raksha Bandhan
message.

------------------------------------------------------------
FEATURES
------------------------------------------------------------

1. Beautiful Raksha Bandhan landing page
2. Surprise opening animation
3. Animated gift box
4. Special Gujarati message
5. Animated envelope / letter
6. Typing text effect
7. Floating hearts
8. Floating particles
9. Sparkle and glow effects
10. Firework / celebration effects
11. Final surprise message
12. Responsive design
13. Mobile friendly
14. Tablet friendly
15. Desktop friendly
16. Gujarati + English font support
17. No image required
18. Simple HTML/CSS/JavaScript project

------------------------------------------------------------

------------------------------------------------------------

HTML5
CSS3
JavaScript
Google Fonts

IMPORTANT
------------------------------------------------------------

Keep file names and folder names correct.

Do not move CSS files without updating the
<link> paths in HTML.

For pages inside the "pages" folder, use:

../assets/css/style.css

For index.html, use:

assets/css/style.css
